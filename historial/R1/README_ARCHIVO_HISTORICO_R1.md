# Archivo histórico AOS 0.1.9 R1

Esta carpeta conserva la evidencia de la baseline inmediatamente anterior a
AOS 0.1.9 R2. La distribución completa se entrega por separado como:

`AOS_0_1_9_R1_HISTORICO.zip`

SHA-256:

`7032b765346828bb26dc8ceada580dbe3fc6166ff879db427b361d5fc6637cb3`

El ZIP histórico es una copia byte a byte de la entrega R1 auditada. No debe
modificarse ni utilizarse como punto de partida para nuevos desarrollos. Las
nuevas ramas deben partir de R2, salvo que una decisión de arquitectura indique
expresamente otra baseline.

## Evidencia preservada

- changelog R1;
- manifiesto R1;
- checksums internos R1;
- verificadores originales R1, guardados como texto no ejecutable;
- menú principal R1, guardado como texto no ejecutable;
- documento de transición R1 a R2.

Los archivos terminados en `.m.txt` son evidencia histórica y no se agregan al
path de GNU Octave.
