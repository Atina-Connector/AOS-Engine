# AOS 0.1.9 - Puerta de entrada a 0.2.0

- Nuevo menu principal basado en bancos de trabajo.
- Todos los modulos activos, beta, roadmap y conceptuales permanecen visibles.
- AOS Viewer queda en la ultima posicion.
- AOS Fluids pasa a ser un banco transversal independiente.
- AOS Solvers aparece como espacio cientifico separado por disciplinas.
- AOS 3D Core se define como servicio transversal para pozos, redes, electricidad, instalaciones y geologia.
- AOSCAD DEV1 R9.1 y su dominio hidraulico selectivo se mantienen integrados.
- Se agregan contratos JSON para alimentar el futuro frame con cinta de AOS 0.2.0.
- Se conserva el menu historico como compatibilidad.
- No se modifican las ecuaciones de los solvers existentes.
