# Menu jerarquico AOSCAD DEV1 R8

## Menu principal

1. CAD 2D / DXF
2. CAD 3D / STEP
3. Topologia, capas y datos tecnicos
4. Simulacion hidraulica
5. Reportes `.aoscad` y resultados
6. Sincronizacion y recarga
7. Plataforma y diagnosticos

## Submenu hidraulico

El submenu concentra el ciclo tecnico completo:

1. Preparar modelo desde el DXF activo.
2. Configurar solver y propiedades del fluido.
3. Consultar configuracion efectiva y motores disponibles.
4. Validar topologia y condiciones de borde.
5. Ejecutar la simulacion.
6. Consultar resumen.
7. Consultar tabla nodal.
8. Consultar tabla por tramo.
9. Consultar todas las tablas.
10. Colorear el modelo con resultados.
11. Guardar `.aoscad` simple.
12. Guardar `.aoscad` enriquecido.
13. Ejecutar el flujo completo.
14. Ejecutar el selftest.
15. Acceder al demo heredado.

Las tablas siguen siendo el resultado tecnico principal. El dibujo coloreado es una representacion secundaria.
