# AOS 0.1.9 R2 HF2 - referencia historica

HF3 fue construido sobre la distribucion completa AOS 0.1.9 R2 HF2.
HF2 queda identificado como la linea base anterior a la restauracion del
gestor transversal de punzados. No se eliminaron archivos de HF2 durante
la construccion de HF3; los cambios se distribuyen tambien como hotfix
reversible con respaldo externo.
