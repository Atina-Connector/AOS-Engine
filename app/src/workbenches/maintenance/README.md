# AOS MAINTENANCE workbench

Transitional namespace for AOS 0.2.0. The operational implementation remains in the current `src/menu`, `src/core` and `src/modulos` paths during AOS 0.1.9. Do not duplicate solver physics here.

## Frontera ENV-02

AOS Maintenance es responsable de integridad, confiabilidad, pulling, priorización, economía de intervención y ejecución de acciones correctivas.

AOS Environmental es un banco independiente. Maintenance consume criticidad, score ambiental/HSE, recomendaciones y verificaciones mediante contratos públicos; no mantiene un modelo ambiental paralelo. El entrypoint independiente ya está implementado; el acceso histórico se conserva únicamente como compatibilidad.
